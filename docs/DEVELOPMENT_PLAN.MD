# DEVELOPMENT PLAN — Muzzzic

## 1. Общие принципы

### 1.1. Порядок разработки
1. **Бэкенд первым** — API должно быть готово до фронтенда
2. **Каждый этап завершается проверкой** — код запускается и тестируется перед переходом дальше
3. **Итеративность** — от простого к сложному, от рабочего скелета к полному функционалу

### 1.2. Роль ИИ-агента
- Каждый этап — это **промпт** для ИИ-агента (Cursor, Claude, Copilot)
- Агент получает ссылки на SPEC-файлы и конкретную задачу
- Агент генерирует код, разработчик проверяет и коммитит

**Промпт для ИИ:**

mood_id: артисты, у которых есть песни с этим настроением

GET /api/v1/search/?query= — глобальный поиск

Формат ответа: { "data": ..., "meta": { "total", "page", "page_size" } }

Пагинация: page (default 1), page_size (default 20, max 100)

## 3. Порядок выполнения для ИИ-агентов

### Правила:
1. Каждый этап — отдельный промпт
2. После каждого этапа — проверка и коммит
3. Если этап не проходит критерии — доработка до соответствия
4. Не переходить к следующему этапу, пока текущий не завершён

### Рекомендуемая последовательность коммитов:
git add .
git commit -m "feat: этап 1 — инициализация проекта"
git commit -m "feat: этап 2 — модели данных"
git commit -m "feat: этап 3 — публичные API"
git commit -m "feat: этап 4 — админские API"
git commit -m "feat: этап 5 — базовая структура фронтенда"
git commit -m "feat: этап 6 — карусели фильтров"
git commit -m "feat: этап 7 — результаты и плеер"
git commit -m "feat: этап 8 — полировка"
