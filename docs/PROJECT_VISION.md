# PROJECT VISION — MusicMe

## 1. Миссия проекта
Одностраничный веб-каталог музыкальных треков, который:
- Демонстрирует портфолио артиста в стильном минималистичном интерфейсе
- позволяет управлять треками, помещая их в альбымы, присваивая настроение и жанр
- Предоставляет удобную навигацию по трекам через каскадные фильтры и поиск
Бэк: python + django + postgres. Фронт: vite + pinia. Сборка с помощью docker

## 2. Целевая аудитория
- **Посетители:** Любой пользователь интернета без авторизации
- **Администратор:** Владелец каталога (вы), управляет контентом через скрытую админ-панель

## 3. Ключевые функции

### 3.1. Публичная часть (Главная страница)
- **OAuth-панель (имитация):** Стилизованные кнопки "Войти через Google / Яндекс / VK". При клике — модальное окно с сообщением "Раздел в разработке"
- **Поиск:** Нативная строка поиска по названию трека и имени исполнителя (в верхней части страницы)
- **Каскадные фильтры (4 уровня):** Горизонтальные карусели для последовательного выбора:
  1. Жанр (может быть несколько у трека)
  2. Настроение (может быть несколько у трека)
  3. Исполнитель (один у альбома)
  4. Альбом (может быть несколько у исполнителя)
- **Результаты:** В нижней части страницы отображаются альбомы/треки, соответствующие выбранным фильтрам и поисковому запросу. Отображение — плиткой (обложки альбомов)
- **Плеер:** Реальный аудиоплеер для воспроизведения конкретного выбранного трека

### 3.2. Административная часть (Private)
- **Аутентификация:** Вход по логину/паролю (Django Admin)
- **Управление контентом:** CRUD операции для:
  - Исполнителей
  - Альбомов (с обложками)
  - Треков (с аудиофайлами, жанрами, настроениями)
  - Жанров и Настроений (справочники)

## 4. Нефункциональные требования

### 4.1. Масштаб
- Библиотека рассчитана на **~100 альбомов** (текущий масштаб)
- Архитектура должна позволять рост до 1000+ альбомов без переписывания

### 4.2. Дизайн и UX
- Эстетика: Минимализм, тёмная тема (по умолчанию), акцент на обложки
- Карусели: Плавные горизонтальные прокрутки (scroll-snap)
- Адаптивность: Корректное отображение на десктопе и мобильных устройствах

### 4.3. Производительность
- Первая загрузка страницы: < 3 секунд
- Подгрузка данных фильтров и результатов: асинхронно (REST API)
- Аудиофайлы: Стриминг, без полной загрузки перед воспроизведением

## 5. Технологический стек

### 5.1. Бэкенд
- **Python 3.12** + **Django 5.x**
- **Django REST Framework** для API
- **База данных:**  PostgreSQL (через Docker)

### 5.2. Фронтенд
- **Vue 3** (Composition API)
- **Vite** как сборщик
- **Pinia** для state management
- **Tailwind CSS** для стилизации
- **Quasar** (опционально, для готовых компонентов каруселей/плеера)

### 5.3. Инфраструктура
- **Docker** и **Docker Compose** для локального запуска
- **GitHub** для хранения репозитория
- **GitHub Actions** для CI/CD (опционально)

## 6. Границы проекта (Out of Scope)

### 6.1. Не входит в MVP
- Реальная OAuth-аутентификация (Google, Яндекс, VK) — только имитация
- Регистрация пользователей
- Пользовательские плейлисты
- Комментарии/лайки/репосты
- Статистика прослушиваний
- Рекомендательная система
- Эквалайзер / визуализация аудио
- **Production-развёртывание (gunicorn, nginx, HTTPS, CI/CD)**

### 6.2. Сознательные упрощения
- Нет сложных прав доступа (только админ и аноним)
- Нет кэширования (на текущем масштабе не требуется)
- Нет версионирования API (используем `/api/v1/`)

## 7. Критерии готовности MVP

- [ ] Приложение запускается через `docker compose up`
- [ ] Главная страница отображает каскадные фильтры (жанр → настроение → артист → альбом)
- [ ] Поиск работает по названию трека и имени исполнителя
- [ ] Результаты отображаются плиткой с обложками
- [ ] Плеер воспроизводит выбранный трек
- [ ] Админ может загрузить новый альбом с треками, жанрами и настроениями
- [ ] OAuth-кнопки показывают заглушку "В разработке"
- [ ] README.md содержит инструкцию по локальному запуску

## 8. Риски и открытые вопросы

- **Риск:** Сложность каскадных фильтров может замедлить разработку
  - **Митигация:** Начать с простого API, затем усложнять
- **Риск:** Vue + Django интеграция может вызвать CORS-проблемы
  - **Митигация:** Настроить Django CORS с самого начала
- **Вопрос:** Нужна ли пагинация результатов при 100+ альбомах?
  - **Ответ:** Пока нет, отложить до реальной необходимости
