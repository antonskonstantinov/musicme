# FRONTEND SPECIFICATION — Muzzzic

## 1. Общая концепция

Одностраничное приложение (SPA) с тёмной темой, минималистичным дизайном и акцентом на обложки альбомов.

**Атмосфера:** "Современный музыкальный сервис" (Spotify / Apple Music / Яндекс.Музыка), но без лишней сложности.

**Ключевая метафора:** Фасетный поиск — пользователь видит все фильтры одновременно и свободно комбинирует их в любом порядке.

## 4. Компоненты

### 4.1. HeaderBar

**Описание:** Верхняя панель.

**Элементы:**
- Логотип "Muzzzic" (слева)
- Строка поиска (по центру)
- Кнопки OAuth (справа): Google, Яндекс, VK

**Поведение:**
- Ввод в строку поиска (мин. 2 символа) запускает глобальный поиск через `GET /api/v1/search/?query=...`
- Поиск активируется с задержкой (debounce 500 мс)
- При клике на любую OAuth-кнопку открывается модальное окно с текстом "Раздел в разработке"
- Кнопки OAuth — стилизованные, выглядят как настоящие (логотип + текст + фирменные цвета)

**Состояния:**
- Пустой поиск — ничего не происходит
- Поиск активен — показывать спиннер в строке поиска
- Результаты поиска — отображаются в секции результатов (п. 4.6)
- Поиск не дал результатов — сообщение "По запросу '...' ничего не найдено"

**Взаимодействие с фильтрами:**
- Поиск работает ПАРАЛЛЕЛЬНО с фильтрами
- Если активен и поиск, и фильтры — результаты объединяются через **AND**
- При вводе поискового запроса фильтры НЕ сбрасываются

### 4.2. FilterCarousel (универсальный компонент)

**Описание:** Горизонтальная карусель с прокруткой (scroll-snap).

**Входные параметры (props):**

| Prop | Тип | Обязательный | Описание |
|------|-----|--------------|----------|
| `items` | Array | Да | Список элементов для отображения |
| `selectedId` | Number | Нет | ID выбранного элемента (или null) |
| `title` | String | Да | Название карусели ("Жанр", "Настроение"...) |
| `loading` | Boolean | Нет | Флаг загрузки |
| `emptyText` | String | Нет | Текст при пустом списке |

**События (emits):**

| Событие | Параметр | Описание |
|---------|----------|----------|
| `select` | `item` | Пользователь кликнул по элементу |
| `clear` | — | Пользователь кликнул по кнопке "Очистить" |

**Визуальное поведение:**
- Карточки располагаются горизонтально
- Каждая карточка — скруглённый прямоугольник с текстом
- Выбранная карточка подсвечивается (акцентный цвет + обводка)
- Прокрутка — плавная, через CSS `scroll-snap-type: x mandatory`
- На мобильных — swipe, на десктопе — скролл колёсиком + стрелки (опционально)
- Если есть выбранный элемент — рядом с заголовком появляется кнопка "Очистить" (крестик)

**Состояния:**
- `loading = true` — показывать скелетон (placeholder-карточки)
- `items.length === 0` и `loading = false` — показывать `emptyText`
- `items.length > 0` — обычный режим

### 4.5. AlbumGrid (Результаты)

**Описание:** Сетка обложек альбомов или список треков.

**Режимы отображения:**

| Режим | Условие | Содержимое |
|-------|---------|------------|
| Сетка альбомов | Выбраны фильтры (любые) или ничего не выбрано | Плитка альбомов |
| Список треков | Выбран конкретный альбом | Треки выбранного альбома |
| Результаты поиска | Активен поисковый запрос | Смешанный результат (артисты, альбомы, треки) |

**Формат сетки альбомов:**
- Плитка (grid): 2 колонки на мобильных, 4-6 на десктопе
- Каждая карточка: обложка альбома (квадратная), название, имя артиста, год
- При клике на карточку — загружаются треки альбома (переход в режим списка треков)

**Формат списка треков:**
- Заголовок: обложка альбома + название + артист + год
- Список: номер, название, длительность, жанры/настроения (теги)
- Кнопка "Play" напротив каждого трека

Пустые состояния:

Ситуация	Сообщение
Нет фильтров и нет поиска (начальное состояние)	Автоматически показывается первый альбом (минимальный id) и его треки
Фильтры не дали результатов	"Ничего не найдено. Измените параметры."
Поиск не дал результатов	"По запросу '...' ничего не найдено"
База данных пуста	"Контент скоро появится"

### 4.8. Результаты поиска

**Описание:** Отображается при активном поисковом запросе.

**Секции (если есть результаты):**
1. **Артисты:** Имя + количество альбомов. Клик → установить фильтр "Артист"
2. **Альбомы:** Обложка + название + артист. Клик → открыть треки альбома

### 4.9. AudioPlayer

**Описание:** Нижний фиксированный плеер.

**Отображение:**
- Обложка трека (или альбома) — миниатюра
- Название трека
- Имя артиста — название альбома
- Кнопки управления: Play/Pause, Stop, Перемотка (seek bar)
- Время: текущее / общее
- Кнопка "Закрыть" (убрать плеер)

**Поведение:**
- Появляется при выборе трека
- Воспроизведение — через HTML5 Audio API
- Стриминг: используется `audio_url` из API, с поддержкой Range (автоматически браузером)
- Переключение треков: если пользователь кликает другой трек — плеер переключается
- Автопереход: после окончания трека играет следующий в альбоме (если есть)
- Кнопка "Закрыть" — останавливает воспроизведение и скрывает плеер

**Состояния:**
- Нет трека — плеер скрыт
- Трек загружается — спиннер
- Трек играет — кнопка Pause
- Трек на паузе — кнопка Play

## 5. Взаимодействие с API

### 5.1. Загрузка при старте
Шаг 1. Параллельно:
- GET /api/v1/genres/          (для карусели жанров)
- GET /api/v1/moods/           (для карусели настроений)
- GET /api/v1/artists/         (для карусели артистов — все артисты)
- GET /api/v1/albums/          (для карусели альбомов — все альбомы)

Шаг 2. После получения списка альбомов:
- Определить первый альбом (минимальный id)
- GET /api/v1/albums/{first_album_id}/  (детали с треками)

Шаг 3. Отобразить:
- Секция результатов: треки первого альбома
- Плеер: первый трек альбома (на паузе, не воспроизводится автоматически)

---

### 5.2. Фасетная фильтрация

| Действие пользователя | Запрос |
|----------------------|--------|
| Выбор жанра | `GET /api/v1/artists/?genre_id=1` + `GET /api/v1/albums/?genre_id=1` |
| Выбор настроения | `GET /api/v1/artists/?mood_id=2` + `GET /api/v1/albums/?mood_id=2` |
| Выбор артиста | `GET /api/v1/albums/?artist_id=5` |
| Выбор альбома | `GET /api/v1/albums/10/` (детали с треками) |
| Сброс жанра | `GET /api/v1/artists/?mood_id=2` (если настроение выбрано) |
| Сброс настроения | `GET /api/v1/artists/?genre_id=1` (если жанр выбран) |
| Сброс артиста | `GET /api/v1/albums/?genre_id=1&mood_id=2` (если жанр/настроение выбраны) |
| Сброс всех | `GET /api/v1/artists/` + `GET /api/v1/albums/` |

**Логика:**
- Карусель артистов обновляется при изменении ЖАНРА или НАСТРОЕНИЯ
- Карусель альбомов обновляется при изменении ЖАНРА, НАСТРОЕНИЯ или АРТИСТА
- Результаты внизу обновляются при ЛЮБОМ изменении фильтров
- Все запросы — асинхронные, с debounce (300 мс) для избежания лишних вызовов

## 6. Состояния (Pinia)

### 6.1. `useCatalogStore`

**Хранит:**
- `genres: []` — список жанров (загружается при старте, не меняется)
- `moods: []` — список настроений (загружается при старте, не меняется)
- `artists: []` — текущий список артистов (обновляется при фильтрации)
- `albums: []` — текущий список альбомов (обновляется при фильтрации)
- `currentAlbum: null` — выбранный альбом (с треками)
- `searchResults: null` — результаты поиска
- `initialAlbumLoaded: false` — флаг, что начальный альбом загружен
- `isInitialLoad: true` — флаг первичной загрузки

**Действия:**
- `fetchGenres()`
- `fetchMoods()`
- `fetchArtists(genreId, moodId)`
- `fetchAlbums(artistId, genreId, moodId)`
- `fetchAlbumDetail(albumId)`
- `search(query)`
- `clearSearch()`
- `loadInitialContent()` — загружает первый альбом и его треки при старте
---

### 6.2. `useFiltersStore`

**Хранит:**
- `selectedGenre: null`
- `selectedMood: null`
- `selectedArtist: null`
- `selectedAlbum: null`
- `searchQuery: ''`

**Геттеры:**
- `activeFilters` — массив выбранных фильтров (для чипов)
- `activeFiltersCount` — количество выбранных фильтров
- `hasActiveFilters` — есть ли хоть один выбранный фильтр
- `isDefaultState` — true, если ни один фильтр не выбран и поиск пуст

**Действия:**
- `setGenre(genre)` — устанавливает жанр, НЕ сбрасывает другие фильтры
- `setMood(mood)` — устанавливает настроение, НЕ сбрасывает другие фильтры
- `setArtist(artist)` — устанавливает артиста, НЕ сбрасывает другие фильтры
- `setAlbum(album)` — устанавливает альбом, НЕ сбрасывает другие фильтры
- `clearGenre()` — сбрасывает только жанр
- `clearMood()` — сбрасывает только настроение
- `clearArtist()` — сбрасывает только артиста
- `clearAlbum()` — сбрасывает только альбом
- `resetAll()` — сбрасывает все фильтры
- `setSearchQuery(query)` — устанавливает поисковый запрос

---

### 6.3. `usePlayerStore`

**Хранит:**
- `currentTrack: null` — текущий трек
- `isPlaying: false`
- `currentTime: 0`
- `duration: 0`
- `queue: []` — очередь воспроизведения (треки альбома)
- `currentIndex: -1` — индекс текущего трека в очереди

**Действия:**
- `playTrack(track, queue)` — начать воспроизведение трека с очередью
- `togglePlay()` — play/pause
- `stop()` — остановить и скрыть плеер
- `seekTo(seconds)` — перемотка
- `next()` — следующий трек в очереди
- `prev()` — предыдущий трек в очереди

Логика:

При isDefaultState === true — показывать первый альбом
При сбросе всех фильтров (resetAll()) — снова показывать первый альбом

## 7. UX-требования

### 7.1. Анимации
- Плавное появление каруселей (fade-in)
- Плавная прокрутка каруселей (scroll-behavior: smooth)
- Анимация появления плеера (slide-up)
- Спиннер при загрузке данных
- Плавное переключение режимов (сетка ↔ список треков)

### 7.2. Адаптивность

| Устройство | Плитка альбомов | Карусели |
|------------|-----------------|----------|
| Mobile (< 768px) | 2 колонки | Полноширинные, swipe |
| Tablet (768-1024px) | 3-4 колонки | Полноширинные |
| Desktop (> 1024px) | 5-6 колонок | Полноширинные |

### 7.3. Пустые состояния

| Ситуация | Сообщение |
|----------|-----------|
| Нет жанров | "Жанры не добавлены" |
| Нет настроений | "Настроения не добавлены" |
| Нет артистов (из-за фильтров) | "Нет артистов с такими параметрами" |
| Нет альбомов (из-за фильтров) | "Нет альбомов с такими параметрами" |
| Нет результатов | "Ничего не найдено. Измените параметры." |
| Поиск без результатов | "По запросу '...' ничего не найдено" |
| Нет выбранных фильтров и нет поиска | Автоматически показывается первый альбом (минимальный id) и его треки |

### 7.4. Обработка ошибок
- Ошибка сети: Toast-уведомление "Не удалось загрузить данные"
- Ошибка API: Показывать сообщение из `error.message`
- Таймаут запроса: Повторная попытка (кнопка "Повторить")

### 7.5. Производительность
- Debounce для поиска: 500 мс
- Debounce для фильтров: 300 мс
- Кэширование жанров и настроений (не перезапрашивать)
- Ленивая загрузка обложек (lazy loading для изображений)
